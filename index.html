    About the model

    This tool uses a {{ meta.model_name|lower }} model trained on {{ '{:,}'.format(meta.n_rows) }} used-car listings from {{ meta.data_period }}, using only details a buyer can actually know: brand, model, variant, fuel, transmission, body type, city, age, kilometers, and number of owners. It was chosen over the other candidates by 5-fold cross-validation, then scored once on a held-out 20% test set.
